# dsh-preset-prompts

DSH 预设提示词插件：内置 10 条思维框架提示词 + 自定义提示词管理（变量、分组、版本历史），在输入框上方弹出面板，一键注入会话输入框。数据本地落盘（`~/.askit/prompts.json`），不依赖任何外部服务。

## 安装

```bash
dsh plugin add dsh-preset-prompts@latest
# 重启 dsh web
```

安装后自动挂载：输入框工具行出现「预设提示词」按钮；设置面板新增「预设提示词」管理页。

## 功能

- 10 条内置模板：苏格拉底式提问 / 双层解释法 / 反向拆解 / 横纵分析法 / 事实核查 / 专家会诊 / 第一性原理 / 跨领域借解 / 双向钢人论证 / 用最小实验替代空想
- 自定义提示词：名称 / 应用场景 / 所属分组 / 变量（`$变量名`，正文内 chip 编辑 + `$` 联想插入）/ 版本历史（最多 10 版，可回退）
- 面板：选模板 → 填变量 → 预览（有序列表自动换行）→ 注入输入框（自动聚焦、光标置尾）
- 内置模板可编辑、删除，支持按条「恢复初始」
- 附带 `fact_check` 模型工具：事实核查（五级核查法的联网版），Agent 可在任务中自主调用
